# Phase 10 Plan 01: Досье мировых конкурентов

**Один абзац:** Составлено досье на 13 мировых ивент-агентств по единому шаблону (позиционирование / SEO-подход / SMM / сигнатурные форматы / визуал / что взять) с балансом по регионам — Европа 6, Америка 4, Азия/ОАЭ 3. Досье грунтовано реальным веб-ресёрчем (сайты, разделы, структура URL, соцсети, отраслевые рейтинги Event Marketer «It List»), а не выдумано. Ключевая находка: топ-агентства продают опыт через **именованные продукты-форматы и собственные методологии** (Jack Morton — суб-бренды Jack X/Jack 39, GPJ — Strategic Experience Mapping®, VOK DAMS — «Live Marketing» + трендовые исследования, Pico — Experience Pulse) — это прямое сырьё для линейки форматов «Крыльев» (Фаза 13) и контент-хаба (Фаза 14).

## Что сделано

### Задача 1: Зафиксировать решение D-10 (бюджет) — чекпоинт
- Режим `--auto`: чекпоинт-решение авторазрешён в **дефолтную опцию «free»** без паузы и вопроса Марии.
- **Решение: бюджет фазы = 0 ₽**, только бесплатные инструменты и ручной осмотр.
- Инструменты: сайты агентств и их структура URL/разделов, публичные кейсы, соцсети (LinkedIn/Instagram/YouTube), отраслевые рейтинги (Event Marketer «It List / Agency 100», BizBash, Eventex). Ahrefs/SEMrush не использовались (недоступны из РФ + для целей фазы избыточны).

### Задача 2: Расширенные досье (5 агентств, все 3 региона)
- **Jack Morton** (США) — «experience brand», суб-бренды Jack X / Jack 39 / Genuine / Jack Health, LinkedIn ~108 тыс., контент-хаб «Experience IQ».
- **VOK DAMS** (Германия) — владение категорией «Live Marketing», именованные исследования (Mega Trends, Digi-Index, SDG Event Compass) как SEO-магнит, подкаст «Make My Monday».
- **Pico** (Гонконг) — «Total Brand Activation», собственная методология измерения «Experience Pulse», кластерная структура услуг.
- **George P. Johnson / GPJ** (США) — зарегистрированная методология «Strategic Experience Mapping®», самый агрессивный SEO (посадочные под коммерческие ключи), регионально децентрализованный SMM.
- **Sledge** (Великобритания) — устойчивость как тон голоса, блог с практическими гайдами; визуал — ссылка на inspiration.md.

### Задача 3: Сжатые досье до 13 агентств + баланс по регионам
- **Freeman** (США), **Colin Cowie** (США), **Uniplan** (DE), **Marbet** (DE), **MCI Group** (CH), **Cheerful Twentyfirst** (UK), **27Names** (сеть ЕС), **Blink Experience** (Дубай).
- Добавлен подраздел `## Баланс по регионам` с таблицей распределения.
- Добавлен подраздел «Что дальше» — вход в Фазы 13/14/16.

## Ключевые находки

1. **Продуктизация форматов.** Топы не продают «мероприятие» — они продают **именованные продукты**: суб-бренды (Jack Morton), зарегистрированные методологии (GPJ Strategic Experience Mapping®), продуктовые платформы (Marbet m.next/m.guest), фирменные индексы (MCI Association Engagement Index, VOK DAMS Digi-Index). Прямой ориентир для Фазы 13: «Крыльям» назвать 1–2 своих флагманских формата.
2. **SEO-модели делятся на три типа.** «Product-led» (VOK DAMS, Marbet — именованные исследования/платформы), «research/benchmark» (MCI, Freeman — отраслевые отчёты как магнит для ссылок), «редакционный блог» (Uniplan, Sledge, Cheerful — практические гайды из своей работы). Для «Крыльев» реалистична третья модель (1 практический материал в месяц).
3. **Посадочные под формат/локацию** — общий приём (Jack Morton `/offices/dubai/`, GPJ коммерческие лендинги, Pico локальные страницы). Ложится в семантику Фазы 14: «корпоратив в Калининграде», «тимбилдинг в Калининграде».
4. **Основной B2B-канал мира — LinkedIn** (у всех: Jack Morton ~108 тыс., Pico, GPJ, MCI, Freeman ~71 тыс.). **Не портируется** — LinkedIn в РФ заблокирован; заменяется Telegram в режиме информирования.
5. **«Локальность как продукт»** (Blink Experience «Beyond Local», 27Names «локальное агентство = точка контакта») — прямая параллель отстройке «Крыльев» для иногородних заказчиков.

## Флаги непортируемости (D-11 + Pitfall #8)

- **38-ФЗ:** продающая механика мировых в соцсетях (цены, CTA «закажи», оценочные прилагательные в Instagram) у нас **запрещена** — только режим «информирования» (штраф 4–20 тыс ₽/пост для ИП). Помечено в досье.
- **Масштаб/бюджет:** глобальные сети офисов, мега-экспо (Pico), auto shows (GPJ), city-scale festivals (Blink), ISO/B Corp сертификации (Sledge) — избыточно для регионального агентства с бюджетом ≈0.
- **Тон:** досье выдержано ровно, без противопоставления — мировые агентства как учебник приёмов, не мишень (Pitfall #8).

## Deviations from Plan

- Выбрано 13 для чистого регионального баланса (Европа 6 / Америка 4 / Азия 3) — в пределах диапазона, не отклонение.

### Метод ресёрча: параллельные веб-агенты
- Для грунтовки досье реальными данными запущены веб-ресёрч по регионам (WebSearch/WebFetch). Данные по всем агентствам проверены на публичных источниках (сайты, соцсети, рейтинги). Часть американских досье (Jack Morton, GPJ, Freeman) уточнена по возвращённым фактам (суб-бренды, слоганы, именованные отчёты) — повысило точность.

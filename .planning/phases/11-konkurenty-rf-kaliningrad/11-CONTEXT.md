## Implementation Decisions

### Список конкурентов (решено с Машей)

- **D-01:** Местные агентства Калининграда — 8 шт. Двухуровневая глубина:
  - **Главные ориентиры (досье глубже):** «Фабрика», «Марченко» — с ними реально сравнивают «Крылья».
  - **Остальные местные (досье компактнее):** «Апполонов», «Корпус», «Балтма турс», «Киселёва», «Гранат», «Море».
  - Список не закрыт: если в ходе ресёрча всплывут новые заметные игроки — добавить.
- **D-02:** Внутренний инсайд Маши: Мария раньше работала в «Фабрике», в городе многие об этом знают. Это **полезный факт** (знание их кухни изнутри) — фиксируем в досье как внутреннюю заметку. В публичных текстах сайта НЕ упоминаем (тон без противопоставления, см. canonical_refs → competitors.md, objections.md).
- **D-03:** «Марченко» — работает фактически одна, много проектов; отметить это как точку и силы (личный бренд), и уязвимости (ограниченная ёмкость) — материал для отстройки.
- **D-04:** Федеральные агентства — конкретных имён у Маши нет. Список собирается с нуля поиском: отраслевые рейтинги РФ + кто публично берёт региональные/калининградские проекты. Объём — 5–10 шт. (per Success Criteria).

### Оценка каждого конкурента — структура досье (Claude's Discretion, зафиксировано)

- **D-05:** Единый шаблон досье на каждого: название; сайт (есть/нет, ссылка); специализация/позиционирование; **SEO-видимость** (индексируется ли, по каким запросам/кластерам виден, примерный объём/качество органики); **SMM** (площадки, активность, форматы, приблизительные охваты); сильные стороны; слабые стороны; внутренний инсайд (если есть). Для «Фабрики» и «Марченко» — расширенный разбор, для остальных — сжатый.

### Инструменты и бюджет (Claude's Discretion, зафиксировано)

- **D-06:** По умолчанию — **только бесплатные инструменты**: Яндекс.Wordstat, ручная проверка выдачи Яндекс/Google по ключам, визуальный осмотр сайтов, TGStat (бесплатный) и просмотр соцсетей для SMM-оси, Rusprofile / Контур.Компас (бесплатный лимит) для юр-данных федералов.
- **D-07:** Платный разовый доступ (Keys.so / SpyWords, ~990–1200 ₽ на сутки) для точной SEO-видимости — **только опционально**, если бесплатных прикидок окажется недостаточно для честной оценки оси SEO. Перед любой тратой — спросить Машу. Бюджет фазы по умолчанию = 0 ₽.

### Отстройка «Крыльев» (Claude's Discretion, зафиксировано)

- **D-08:** 3–5 конкретных точек, где «Крылья» реально сильнее. Формулировать **через ценность** (надёжность + локальная экспертиза Калининграда), НЕ через минусы конкурентов и НЕ через цену/демпинг (Pitfall #8).
- **D-09:** Применение отстройки — **внутреннее**: скрипты аутрича (Фаза 15) и ответы на возражение «а почему не они». В публичных текстах сайта конкурентов не называем; отстройка может проявляться неявно (блок «почему иногородним» и т.п.).

### Федералы: конкурент или партнёр (Claude's Discretion, зафиксировано)

- **D-10:** Каждое федеральное агентство пометить тегом: **«конкурент»** (борется за тех же клиентов) или **«потенциальный партнёр»** (мог бы отдать локальную часть проекта «Крыльям» как подрядчику в регионе). По умолчанию большинство федералов — потенциальные партнёры: лобовая конкуренция по масштабу/цене проигрышна, выигрыш — локальная экспертиза.
- **D-11:** Компании с тегом «потенциальный партнёр» формируют отдельный список `outreach-targets.md` — прямой вход в Фазу 15 (PARTNER-01: «Крылья как локальный подрядчик»).

### Claude's Discretion

- Точная вёрстка и порядок секций в артефактах, формулировки досье, выбор конкретных ключей для проверки SEO-видимости, набор отраслевых рейтингов для поиска федералов.

</decisions>

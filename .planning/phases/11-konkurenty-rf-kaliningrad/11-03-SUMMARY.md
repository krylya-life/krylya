Сведены оба набора досье (местные `competitor-kaliningrad.md` и федеральные
`competitor-ru.md`) в два рабочих синтез-артефакта.

### Задача 1 — чекпоинт human-verify (D-02, инсайд по «Фабрике»)
**Подтверждено Марией: «ок».** Формулировка внутренней заметки по «Фабрике»

возражения; в публичных текстах сайта конкуренты не называются (D-09).

### Задача 2 — `differentiation.md`
Отстройка «Крыльев»: **5 точек силы через ценность** (D-08), каждая увязана с
конкретным возражением из `objections.md`:
1. Единственное местное агентство с SEO-сайтом → находят из любого города («как удалённо»)
2. Команда с гарантией замещения → надёжность («сделаете без косяков?»)
3. Локальная экспертиза Калининграда → опора на месте («а почему не они»)
4. Прозрачная 10%-модель → ценность, не демпинг («дорого / ужать»)
5. Готовая «пачка» для внутреннего согласования → («согласуем внутри»)

Раздел «Применение»: материал внутренний (аутрич Фазы 15 + ответы на
возражения); на сайте отстройка проявляется неявно (блоки «Почему иногородним»,
«Как мы работаем», 10%-модель, кейсы). Ни одна точка — не через минусы
конкурентов и не через цену.

### Задача 3 — `outreach-targets.md`
Список целевых компаний для Фазы 15 (вход в PARTNER-01), отобран по тегу
«потенциальный партнёр»:
- **Высокий приоритет:** Авантаж, Eventum Premo
- **Средний:** ESM Group, Red Jolly
- **Низкий / точечно:** Event Rocks, Brownfield, BBDO Events
- **Мониторинг (не аутрич):** WOW! Agency (конкурент)

Ядро аутрича — 4 приоритетные цели (осознанно короткий список под
персонализированный аутрич 5–10 касаний/мес). Отмечено, где добрать в Фазе 15.
**152-ФЗ соблюдён:** только публичные контакты (корпоративные сайты и формы),
без персональных данных ЛПР.

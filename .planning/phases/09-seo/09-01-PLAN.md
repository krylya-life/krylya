Обновить комментарий: «sitemap генерируется кастомным endpoint src/pages/sitemap.xml.ts в кириллице — @astrojs/sitemap нормализует IDN в Punycode и не исключает noindex-страницы».

    2. Создать `src/pages/sitemap.xml.ts` — Astro endpoint, отдающий XML c кириллическими `<loc>` для всех индексируемых маршрутов, КРОМЕ `/thanks/`:
    ```typescript
    import type { APIRoute } from "astro";
    import { business } from "../config/business.ts";

    // Индексируемые маршруты (без /thanks/ — она noindex).
    // Витрины услуг и кейсов + их подстраницы. Список синхронизирован с src/pages/.
    const routes = [
      "/",
      "/services/",
      "/services/corporate-parties/",
      "/services/business-events/",
      "/services/client-events/",
      "/services/teambuilding/",
      "/services/coordination/",
      "/services/private/",
      "/cases/",
      "/pricing/",
      "/about/",
      "/contacts/",
      "/privacy/",
    ];

    export const GET: APIRoute = () => {
      const base = business.urlCyrillic.replace(/\/$/, "");
      const urls = routes
        .map((r) => `  <url><loc>${base}${r}</loc></url>`)
        .join("\n");
      const xml = `<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemap.org/schemas/sitemap/0.9">
${urls}
</urlset>`;
      return new Response(xml, {
        headers: { "Content-Type": "application/xml; charset=utf-8" },
      });
    };
    ```
    ВАЖНО: перед финализацией сверь список `routes` с фактическими маршрутами кейсов. Прогони `ls dist/cases/` после билда и, если есть индивидуальные страницы кейсов (`/cases/<slug>/`), добавь каждую в массив `routes`. Витрины `/cases/` достаточно только если детальных страниц нет; если детальные есть — включить их все. `/thanks/` и `/api/` НЕ включать.

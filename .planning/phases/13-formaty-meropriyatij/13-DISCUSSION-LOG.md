## Реальность vs витрина

### Вопрос 1: Из чего собираем линейку?

| Option | Description | Selected |
|--------|-------------|----------|
| Ядро + «умеем» | Реально проведённые (с кейсом) + форматы «умеем и готовы» под тренды/сегменты, без выдуманных кейсов | ✓ |
| Только реальное | Каждый формат стоит на проведённом мероприятии + кейс; линейка меньше, без трендовых новинок | |
| Поровну с маркировкой | ~50/50 проведённые/новые, каждый явно помечен | |

**User's choice:** Ядро + «умеем»

### Вопрос 2: Чем подпираем «ядровые» форматы?

| Option | Description | Selected |
|--------|-------------|----------|
| Кейс без имени | Реальный проект как доказательство, но без названия клиента (анонимно) | ✓ |
| Кейс с именем | Называем клиентов (Быстринское, ВКЛЮЧИ) — макс. доверие, но статус согласий уточняется | |
| Без кейсов пока | Привязку к кейсам делаем позже, когда согласия точно известны | |

**User's choice:** Кейс без имени
**Notes:** Статус публикации имён клиентов ещё уточняется (Phase 0). Анонимная опора безопасна и дополняется именами позже.

# Phase 13: Линейка форматов мероприятий - Context

**Gathered:** 2026-07-02
**Status:** Ready for planning

<domain>
## Phase Boundary

Упаковать линейку из 10+ именованных форматов мероприятий, чтобы «Крылья» могли конкретно ответить на вопрос «что именно вы проводите?» — не «ивенты под ключ», а названные форматы под сегменты A (девелоперы), B (местный крупный бизнес), C (иногородние/федеральные).

По каждому формату: название + описание «для кого / что внутри / чем цепляет / почему именно Крылья», с явной привязкой к сегменту. 3–5 форматов — с акцентом на калининградскую аутентику для сегмента C.

Результат — артефакт `formats.md` в `.planning/outreach/`, вход для Phase 14 (темы статей /идеи/) и Phase 15 (офферы под сегменты).

**Не в этой фазе:** написание статей и семантика (Phase 14), тексты офферов и аутрич (Phase 15), публикация кейсов на сайте, SMM-подача форматов (Phase 16).

</domain>

<decisions>
## Implementation Decisions

### Наполнение линейки (реальность vs витрина)
- **D-01:** Линейка = **ядро из реально проведённых форматов** + несколько форматов «умеем и готовы делать» под отобранные тренды и сегменты. Гибрид даёт и доверие, и требуемые 10+.
- **D-02:** **Никаких выдуманных кейсов.** Форматы «умеем, но ещё не проводили именно так» подаются честно как предложение/развитие практики, без фальшивых цифр и клиентов. Обоснование берём из трендов (Phase 12) и логики сегмента, а не из несуществующего опыта.
- **D-03:** Ядровые форматы подпираются **реальным проектом как доказательством, но без имени клиента** — анонимно («открытие ЖК у воды», «корпоратив для девелопера»). Безопасно по согласиям (статус публикации имён клиентов ещё уточняется), легко дополнить именами позже.

### Именование форматов
- **D-04:** **Гибрид: яркое продуктовое имя + понятный поисковый подзаголовок.** Пример структуры: «Балтийский берег» — выездной корпоратив на Куршской косе. Имя упаковывает и продаёт, подзаголовок обеспечивает узнаваемость запроса для Phase 14 (статьи под формат).
- **D-05:** **Тема имён — по ситуации.** Где формат завязан на место — берём калининградскую географию/природу в название (Балтика, Куршская коса, форты, янтарь): усиливает локальную отстройку и сразу даёт темы для статей. Где формат универсальный (напр. открытие ЖК) — нейтральное образное имя, не привязанное к гео.

### Claude's Discretion
- Итоговый список конкретных форматов и их точные названия (собираются из входных артефактов: 5 применимых трендов + сигнатурные форматы конкурентов + услуги из `.business/products/`).
- Точное число форматов (10+ — нижняя граница; итог зависит от того, сколько складывается осмысленных, не дублирующих друг друга).
- Внутренняя структура/порядок подачи форматов в `formats.md`.
- Формулировки «почему именно Крылья» по каждому формату (опора на differentiation.md, без сравнений с конкурентами и не через цену).

</decisions>

## Specific Ideas

- Пример структуры имени (D-04): **«Балтийский берег» — выездной корпоратив на Куршской косе**. Имя + поисковый подзаголовок.

<deferred>
## Deferred Ideas

- **Флагманский «сигнатурный» формат-визитка** (вокруг подхода Марии или калининградской аутентики) — идея из приёма мировых агентств; не выбрана к обсуждению в этой фазе, можно ввести при сборке линейки или отдельно.
- **Явная маркировка «проведено / новый формат»** в тексте — рассмотрен вариант «пополам с маркировкой», выбран более мягкий гибрид (D-01/D-02); визуальные пометки не вводим.
- **Баланс по сегментам и точное число форматов** — не фиксировали жёстко; отдано на усмотрение при сборке (Claude's Discretion), с обязательным приоритетом C и 3–5 форматами с калининградской аутентикой.
- **Глубина упаковки каждого формата** (короткое описание vs развёрнутый сценарий с примерной программой) — не обсуждалась; ориентир — шаблон из Success Criteria, детализацию решает планировщик/исполнитель.

</deferred>

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Quality] `[&_h1]:hidden` в MDX-обёртке подстраниц**
- **Found during:** Task 3, осмотр `src/content/services/corporate-parties.md`
- **Issue:** MDX-файлы услуг содержат `# Заголовок` (например, «# Корпоративные мероприятия»). В новой структуре заголовок уже выводится в Hero как H1, и без скрытия мы получили бы дубль (два H1 на странице — нарушение SEO).
- **Fix:** Добавил `[&_h1]:hidden` в arbitrary-селекторы `<article>`. Структурный H1 страницы — один, в Hero. Все H2/H3 из MDX рендерятся нормально.
- **Files modified:** `src/pages/services/[slug].astro`
- **Commit:** включено в fa865fc

**2. [Rule 2 - Quality] Поддержка `<ol>` (нумерованных списков) и `<blockquote>` в MDX-стилях**
- **Found during:** Task 3, осмотр контента (в `corporate-parties.md` есть нумерованный список «5 типов задач»)
- **Issue:** План описал стили только для `[&_ul>li]`. В реальном контенте используются и `<ol>` (нумерованные), и `<blockquote>`. Без стилей они выглядели бы дефолтно (без отступов, без цвета).
- **Fix:** Добавил `[&_ol]:list-decimal [&_ol]:marker:text-[#FFF200]` (жёлтые цифры) и `[&_blockquote]:border-l-2 [&_blockquote]:border-[#FFF200]` (жёлтая левая полоска для цитат, если появятся).
- **Files modified:** `src/pages/services/[slug].astro`
- **Commit:** включено в fa865fc

**3. [Rule 2 - Quality] PricingTeaser у `/services/index.astro` — без блока `Section`/`Container`**
- **Found during:** Task 2
- **Issue:** Изначальная витрина оборачивала `<PricingTeaser />` в Astro-компонент. Новый PricingTeaser уже самостоятельная секция с `lab-bg-alt` и `px-6 py-14 md:px-12 md:py-20`. Двойная обёртка дала бы лишний отступ.
- **Fix:** PricingTeaser теперь подключается одной строкой `<PricingTeaser />`, как самостоятельная секция. Соответствует структуре главной из плана 03.
- **Files modified:** `src/pages/services/index.astro`, `src/pages/services/[slug].astro`, `src/components/blocks/PricingTeaser.astro`
- **Commit:** распределено по 4f4e0b6 + c60f990 + fa865fc

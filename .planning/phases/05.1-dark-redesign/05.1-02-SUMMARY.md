# Phase 05.1 Plan 02: Тёмный фундамент для production-сайта — Summary

**One-liner:** Из песочницы `src/design-lab/` извлечён фундамент тёмной темы для основного сайта: vanilla-Astro версии React-эффектов (Spotlight, Meteors, BorderBeam, MagicCard), глобальный `src/styles/dark.css` со всеми lab-* классами, `DarkLayout.astro` с шапкой/подвалом — и `/test-dark/` для ревью Маши.

## Что сделано

### Task 1 — src/styles/dark.css (commit caf0b30)

Создан **src/styles/dark.css** (394 строки) — глобальный CSS для тёмной темы:

- Тёмные `@theme` токены: `--color-ink: #050507`, `--color-surface: #0B0B10`, `--color-surface-2: #11111A`, `--color-line: #1F1F2A`, `--color-text: #ECECF1`, `--color-text-dim: #9A9AA8` (жёлтый `#FFF200` уже глобальный из global.css)
- Все **keyframes** из песочницы: `spotlight`, `border-beam`, `shimmer-slide`, `spin-around`, `meteor`, `aurora-shift`, `lab-skeleton`, `divider-pulse`, `divider-shimmer`
- Все **lab-* классы**: `.lab-aurora`, `.lab-grid`, `.lab-glow`, `.lab-gradient-text`, `.lab-magic-card`, `.lab-magic-card__glow`, `.lab-skeleton`, `.lab-input`, `.lab-divider`, `.lab-divider-glow`, `.lab-cursor-wings`, `.lab-bg-alt`, `.lab-bg-feature`, `.lab-glow-top`, `.lab-glow-bottom`, `.animate-spotlight`, `.animate-border-beam`, `.animate-shimmer-slide`, `.animate-spin-around`, `.animate-meteor`
- **НЕ** дублируется `@import "tailwindcss"` (он в global.css; dark.css импортируется ПОСЛЕ global)
- **НЕ** дублируется `@font-face` Jost (он в global.css)
- **НЕ** копируется `.lab-root` (тёмный фон будет на `<body>` через Tailwind утилиты в DarkLayout)

### Task 2 — vanilla Astro-компоненты (commit 86bcd88)

Создана папка `src/components/dark/` с 5 vanilla-Astro компонентами (без React):

| Файл | Что делает | Интерфейс |
|---|---|---|
| `Spotlight.astro` | SVG-пятно света с `.animate-spotlight` | `class?: string`, `fill?: string` |
| `Meteors.astro` | Падающие звёзды, случайные позиции на сборке | `number?: number` (default 20) |
| `BorderBeam.astro` | Бегущий по периметру градиентный луч | `size`, `duration`, `colorFrom`, `colorTo`, `anchor`, `borderWidth`, `delay`, `class` |
| `MagicCard.astro` | Карточка с курсорным глоу, slot-based | `class?: string`, `href?: string` (если есть href — рендерится `<a>`, иначе `<div>`) |
| `KaliningradSilhouette.astro` | Линейная графика города, копия 1:1 из песочницы | без props, `md:block` (скрыта на мобиле) |

Все эффекты — чистый CSS+vanilla JS, никаких `client:load` / `client:visible`. pointermove-листенер для `.lab-magic-card` живёт в `DarkLayout`, не в каждой карточке.

# Phase 05.1 Plan 01: Песочница к мобильному ревью Маши — Summary

**One-liner:** Песочница `/design-lab/` переведена на бренд-шрифт Jost (self-hosted), функциональные жёлтые акценты заменены на точный бренд-жёлтый #FFF200, добавлена мобильная адаптация под iPhone Safari (≤390px) — готова к показу Маше с телефона.

### Task 2 — #FFF200 в ключевых бренд-местах (commit 8542ea9)
В `src/pages/design-lab/index.astro` заменены 18+ функциональных вхождений жёлтого с `yellow-300` на `[#FFF200]`:
- Точки и разделители в hero/footer (`text-[#FFF200]` для `·`)
- 7 подчёркиваний H2 (`bg-[#FFF200]`)
- Hover-бордеры карточек услуг/аудитории (`hover:border-[#FFF200]/30`)
- CTA-акценты «Подробнее» в карточках услуг (`text-[#FFF200]` + `bg-[#FFF200]`)
- Бэйдж «Локальная экспертиза» (`text-[#FFF200]` + `bg-[#FFF200]`)
- Метрики в LocalExpertise (`border-[#FFF200]` + `text-[#FFF200]`)
- Клиент-лейбл на карточках кейсов
- Степ-маркер «День Х» + бордер карточки шага
- Underline decoration на email-ссылке и «вернуться на основной сайт»
- Маленькие bullet-точки в списке фактов hero

Оставлены `yellow-300` (декоративные глоу-эффекты, помечены `glow accent`):
- `animate-ping` пингующие точки (4 шт. — оттенок в анимации не критичен)
- `bg-yellow-300/30 blur-md` свечение под H1 (`под ключ`)
- `from-yellow-300/0 ... to-yellow-300/0` градиентная вертикальная линия в timeline
- `.lab-gradient-text` (градиент текста `#FEF08A → #FDE047 → #FBBF24`) — это полу-фабрика, не сплошной бренд-жёлтый. Fallback `#FDE047` тоже оставлен.

### Task 3 — Мобильная адаптация (commit f26a060)
- **Лого в шапке**: `h-14 md:h-28` (56px на мобиле вместо 80px) — шапка не доминирует

- **CTA-кнопки**: добавлен `min-h-[44px]` на 4 кнопки (телефон + Telegram в hero и в контакт-секции) для нажатия пальцем (Apple touch target)

- **Силуэт Калининграда**: уже корректно клипуется через `overflow-hidden` родительской секции (`.lab-bg-feature` имеет `overflow: hidden` в CSS + класс `overflow-hidden` на `<section>`) — горизонтальный скролл не возникает
- `npm run build` проходит за ~10 сек, 19 страниц собрано без ошибок

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Astro JSX-комментарии вне JSX-блоков ломали парсер**
- **Found during:** Task 3 (попытка `npm run build`)
- **Issue:** Добавил пояснительные комментарии `{/* mobile: ... */}` в местах вне JSX-выражений (на уровне обычного HTML-шаблона Astro), а также один `{/* */}` прямо после `return (` внутри `steps.map()` — Astro-парсер ломался с ошибкой `Expected ")" but found "$$render"` на строке 169
- **Fix:** Все `{/* */}` вне JSX-блоков заменены на HTML-комментарии `<!-- -->`. Внутри `.map()` callback JSX-комментарий перенесён ВНЕ `return (...)`
- **Files modified:** `src/pages/design-lab/index.astro`
- **Commit:** включено в `f26a060`

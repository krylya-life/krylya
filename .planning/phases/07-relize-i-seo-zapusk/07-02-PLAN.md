**Что нужно сделать Маше:**

1. **Найти токен Telegram-бота** (один из вариантов):

   **Вариант A — из Netlify (если ещё доступен):**

   - Cloudflare Dashboard → Workers & Pages → krylya (проект) → Settings → Environment variables
   - Production: Add variable
     - Name: `TELEGRAM_BOT_TOKEN`
     - Value: токен из шага 1
     - ⚠️ Поставить флажок **Encrypt** (важно — это секрет)
   - Add variable
     - Name: `TELEGRAM_CHAT_ID`
     - Value: `129375931`
     - Encrypt можно не ставить (это публично известный ID)
   - Save

**Если форма не работает:**

## Decisions Locked (2026-05-16)

### 1. Хостинг → Cloudflare Pages

Текущий preview на Cloudflare Workers — рабочая модель, но без автодеплоя из git и без поддержки форм. Возврат на Netlify рискован — там тот же бесплатный лимит, который мы уже исчерпали в мае.

**Cloudflare Pages** даёт:
- Автодеплой из GitHub (push в main → автообновление сайта)
- Бесплатный SSL для крылья.life и Punycode-формы
- Практически нелимитированный трафик на бесплатном плане
- Работает в России без VPN, хороший CDN

Форма заявок — через **Cloudflare Pages Function** (`/functions/submit.ts`), которая принимает POST и отправляет в Telegram-бот @krylya_zayavki_bot. Аналог Netlify Forms+Function паттерна, переиспользуем `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID=129375931` из Phase 1.

### 2. DNS → nic.ru, доступ у Марии

Домен `крылья.life` зарегистрирован на nic.ru, Маша имеет логин/пароль и может зайти в управление DNS.

**План DNS-переезда:**
1. Подключаем сайт к Cloudflare Pages, получаем preview-URL `<project>.pages.dev`
2. В Cloudflare добавляем домен крылья.life, получаем нэймсервера Cloudflare (вида `xxx.ns.cloudflare.com`)
3. Маша заходит в nic.ru, меняет нэймсервера домена на cloudflare-ные
4. Cloudflare сам выпускает SSL-сертификат и для кириллической, и для Punycode-формы (xn--j1aco8bgs.life)
5. DNS-распространение: до 24-48 часов, обычно несколько часов

**Tilda:** в момент переключения DNS старый сайт автоматически перестанет быть доступен по домену (DNS теперь указывает на Cloudflare). Tilda-аккаунт сохраняем как backup, не удаляем сразу.

## Defaults (закрыто без обсуждения, можно поменять при ревью плана)

### Кодировка URL и SEO

- **Canonical, внутренние ссылки, sitemap URLs** — кириллицей (`https://крылья.life/services/`). Яндекс корректно отображает в сниппетах.
- **TLS Common Name, robots.txt `Host`/`Sitemap`, SMTP** — Punycode (`https://xn--j1aco8bgs.life`). Технические протоколы требуют ASCII.
- **301 со старого сайта:** Tilda была одностраничной (только корень `/`), 301 нужен только с `https://крылья.life/` → `https://крылья.life/` (т.е. это автоматически после переключения DNS). Дополнительные редиректы — если найдём ссылки в индексе Яндекса на разделы Tilda-якорей (`/#section-...`).

### Релиз — постепенный

1. Сначала собираем продакшен на preview-URL Cloudflare Pages, проверяем всё
2. После проверки — Маша меняет нэймсервера в nic.ru
3. После SSL и индексации — фиксируем, что Tilda отключилась

Не «рубим сплеча» — даём день буфера между готовностью preview и переключением DNS.

## Open Questions for Planner

Эти решения планировщик примет сам или вынесет на обсуждение по ходу:

1. **GitHub Actions vs прямая интеграция Cloudflare Pages:** Cloudflare Pages умеет деплоить напрямую из GitHub репо без GitHub Actions. Это проще — рекомендую использовать.
2. **Cache headers:** длительный кеш для статики (CSS, JS, шрифты, картинки), короткий для HTML. Стандартный паттерн.
3. **Превью pull-request деплои:** Cloudflare Pages умеет, можно оставить для будущих PR (не блокер для релиза).
4. **Wrangler CLI:** для управления Cloudflare можно использовать CLI; для разовых задач достаточно веб-кабинета.

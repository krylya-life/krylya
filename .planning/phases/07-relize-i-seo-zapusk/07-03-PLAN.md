  <what-needs-to-happen>
**Что нужно сделать Маше (с Claude рядом):**

1. **Cloudflare Pages → Custom domains:**
   - Зайти в проект `krylya` в Cloudflare Dashboard
   - Workers & Pages → krylya → Custom domains → Set up a custom domain
   - Ввести: `крылья.life` (можно вводить кириллицей, Cloudflare сам сконвертит в Punycode для DNS)
   - Continue

2. **Cloudflare предложит варианты:**
   - Вариант A: Add via DNS records — если домен уже на Cloudflare DNS, просто добавляет CNAME
   - Вариант B: **Change nameservers** — это наш случай (домен на nic.ru). Cloudflare даст ДВА нэймсервера вида:
     - `xxx.ns.cloudflare.com`
     - `yyy.ns.cloudflare.com`
   - Скопировать оба и прислать Claude (запишем в DNS-NOTES.md)

3. **Также добавить Punycode-форму:**
   - Custom domains → Set up a custom domain → ввести: `xn--j1aco8bgs.life`
   - Cloudflare сам поймёт, что это та же зона, что и крылья.life
   - Это нужно, чтобы Cloudflare выпустил SAN-сертификат на обе формы

**Не надо** в Cloudflare DNS добавлять A/CNAME-записи руками — Cloudflare Pages сам подставит правильные записи, как только зона придёт под управление CF (после смены NS в nic.ru).

**После выполнения** прислать Claude:
- Два нэймсервера Cloudflare

  <name>Task 1: Маша подключает Google Search Console (оба property)</name>
  <what-needs-to-happen>
**Что нужно сделать Маше:**

1. **Зайти в Google Search Console:**
   - https://search.google.com/search-console
   - Войти Google-аккаунтом (без VPN — GSC работает в РФ)

2. **Добавить ПЕРВЫЙ property — кириллическая форма:**
   - Главная страница GSC → «+ Добавить ресурс» (Add property)
   - Выбрать тип «URL-prefix» (НЕ «Domain» — Domain-property требует только DNS
     и не различает протоколы, нам важно фиксировать именно https)
   - Ввести: `https://крылья.life/` (с финальным слешем — GSC сохраняет ровно как введено)
   - Continue

3. **Подтверждение прав:**
   - GSC предложит варианты — выбираем **HTML-tag** (простой):
     - Скопировать meta-тег вида `<meta name="google-site-verification" content="abcXYZ...">`
     - Прислать Claude — Claude добавит его в `src/layouts/DarkLayout.astro` в `<head>`
     - После коммита и автодеплоя (1-2 минуты) — нажать «Подтвердить» в GSC
   - Альтернатива: **DNS TXT** — добавить в Cloudflare DNS TXT-запись с указанным значением

   ⚠️ Решаем по факту — Claude поправит код, если выберем HTML-tag, или поможет с DNS, если TXT.

4. **Добавить ВТОРОЙ property — Punycode:**
   - «+ Добавить ресурс» → URL-prefix → `https://xn--j1aco8bgs.life/`
   - Подтверждение тем же способом (тот же meta-тег подойдёт, т.к. это та же зона/тот же контент)

**После выполнения** прислать Claude:
- Скриншот «Property verified» для обоих
- Дата подтверждения

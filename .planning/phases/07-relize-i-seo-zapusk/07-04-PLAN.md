  <name>Task 1: Маша добавляет сайт в Яндекс.Вебмастер (обе формы) и подтверждает права</name>
  <what-needs-to-happen>
**Что нужно сделать Маше (с Claude рядом):**

1. **Зайти в Я.Вебмастер:**
   - https://webmaster.yandex.ru/
   - Войти своим Яндекс-аккаунтом (тот, к которому привязана Метрика 99532899)

2. **Добавить ПЕРВЫЙ сайт — кириллическая форма (primary):**
   - Главная страница Вебмастера → «+ Добавить сайт»
   - Ввести: `https://крылья.life` (можно кириллицей, Вебмастер сам поймёт IDN)
   - Continue → выбрать способ подтверждения

3. **Подтверждение прав** — два рабочих способа:

   **Способ A — DNS TXT-запись (рекомендую, проще для нас):**
   - Вебмастер показывает TXT-запись вида `yandex-verification: a1b2c3d4e5...`
   - Маша заходит в Cloudflare → крылья.life → DNS → Records → Add record
     - Type: TXT
     - Name: `@` (или оставить пустым — это корень)
     - Content: `yandex-verification: a1b2c3d4e5...` (целиком, скопировать из Вебмастера)
     - TTL: Auto
     - Proxy status: DNS only (серая тучка)
   - Save
   - В Вебмастере → «Проверить» — обычно 1–5 минут (DNS быстро на Cloudflare)

   **Способ B — HTML-файл (если DNS неудобен):**
   - Вебмастер даёт файл `yandex_abc123.html` со специфическим содержимым
   - Положить файл в `public/yandex_abc123.html` в репо
   - `git push` — Cloudflare передеплоит через минуту
   - В Вебмастере «Проверить» — файл должен открываться по `https://крылья.life/yandex_abc123.html`

4. **Добавить ВТОРОЙ сайт — Punycode-форма (зеркало):**
   - «+ Добавить сайт» → ввести: `https://xn--j1aco8bgs.life`
   - Подтверждение — Вебмастер обычно автоматически распознаёт, что это та же зона
     (та же TXT-запись подойдёт), и подтверждает быстро

5. **Назначить главное зеркало:**
   - В каждом из двух добавленных сайтов → Индексирование → Переезд сайта или Настройка зеркал
   - Указать главное зеркало: `https://крылья.life`
   - Я.Вебмастер сам поставит 301-связку

**Может занять до 24 часов — Яндекс склеит зеркала не сразу. Это нормально.**

**После выполнения** прислать Claude:

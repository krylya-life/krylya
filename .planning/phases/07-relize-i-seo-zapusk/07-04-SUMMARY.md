# Phase 7, Wave 4 — Яндекс.Вебмастер: подключение и базовая настройка

- **Сайт `https://крылья.life` подтверждён в Я.Вебмастере** под аккаунтом wings.agency@yandex.ru через DNS TXT-запись в Cloudflare. Запись TXT: `yandex-verification: 51de5e79cb2f3268`. Punycode-форма автоматически склеена с кириллической.

- **5 ключевых страниц поданы на «Переобход»** со статусом «В очереди»:

## Что не пошло по плану

**«Оригинальные тексты» больше не существуют.** Инструмент закрыт Яндексом 15 сентября 2020 года. План Wave 4 Task 3 был основан на устаревших данных. Документ [07-04-ORIGINAL-TEXTS.md](07-04-ORIGINAL-TEXTS.md) описывает альтернативы: переобход страниц (сделано) + обход по счётчикам Метрики (followup в Wave 5).

**Обход по счётчикам Метрики не активирован.** При попытке привязать счётчик 99532899 в `/indexing/crawl-metrika/` — диалог закрылся без сообщения об ошибке, статус не изменился. Возможно, требуется, чтобы счётчик Метрики и аккаунт Я.Вебмастера были «склеены» через единый Яндекс-ID, либо нужны дополнительные права. Followup для Wave 5.

**Регион в карточке Яндекс.Бизнеса не указан** — это отдельный путь подтверждения региона, который не входит в Wave 4. Если карточка Я.Бизнес будет заведена в Phase 8 (PLANB-01), регион подтвердится автоматически без ручного указания.

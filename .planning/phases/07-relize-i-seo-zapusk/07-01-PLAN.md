<task type="auto">
  <name>Task 2: robots.txt с Host + Sitemap (Punycode)</name>
  <files>public/robots.txt</files>
  <action>
Создать `public/robots.txt` с содержимым:

```
User-agent: *
Allow: /
Disallow: /api/
Disallow: /thanks/

Host: xn--j1aco8bgs.life
Sitemap: https://xn--j1aco8bgs.life/sitemap-index.xml
```

Почему Punycode в Host/Sitemap: эти директивы для поисковых ботов читаются в ASCII —
Яндекс корректно резолвит Punycode → IDN, а кириллица в robots.txt у некоторых
парсеров вызывает 400. Стандартная практика для IDN-доменов.

Disallow /api/ — там Cloudflare Pages Function /api/contact, не контент.
Disallow /thanks/ — страница «спасибо за заявку», не несёт SEO-ценности, может ловить
паразитный трафик. /privacy/ — публичный, оставляем доступным.

Astro кладёт public/robots.txt в корень dist/ как есть.

## Implementation Decisions

### Workflow для текстов

- **D-01:** Маша выбрала путь **«А»**: Claude пишет драфты на основе `content/pages/services.md` + `.business/products/` + знаний об отрасли, Маша вычитывает и правит. ### 6 категорий на сайте, 4 в `.business/`

- **D-02:** На сайте — **6 SEO-посадочных** (corporate-parties, business-events, client-events, teambuilding, coordination, private). Внутренняя классификация в `.business/products/overview.md` остаётся 4-категорийной (деловые/творческие/развлекательные/координация) — это ОК. Внутренняя стратегическая модель и публичная SEO-структура не обязаны совпадать. Подтверждено Машей 2026-04-26.

### Структура страницы услуги (шаблон для всех 6)

- **D-03:** Универсальный шаблон страницы:
  1. **Hero:** H1 с целевым ключом + локальной привязкой («Организация корпоратива в Калининграде» / «Организация конференции в Калининграде» и т.п.) + подзаголовок 1-2 предложения + CTA «Обсудить мероприятие»
  2. **Что входит в услугу:** список из 6-8 пунктов (концепция, площадка, подрядчики, кейтеринг, программа, координация дня, отчёт, фото/видео)
  3. **Для кого подходит:** 2-3 типичных профиля заказчиков под эту услугу (дев. компания / крупный бизнес / иногородний и т.п.)
  4. **Под какие задачи:** 3-4 типичных повода / задачи («поощрение сотрудников», «работа с дольщиками», «вывод нового продукта»)
  5. **Примеры из практики:** 1-2 реальных кейса из portfolio с цифрами (Быстринское, ВКЛЮЧИ, ДОМ — по релевантности)
  6. **Локальный контекст Калининграда:** 1-2 абзаца про специфику (площадки, сезонность, что характерно региону под эту услугу)
  7. **Как мы считаем стоимость:** короткая отсылка к 10%-модели + ссылка на `/pricing/`
  8. **CTA-блок с формой:** та же форма, что на главной (компонент `<ContactForm>`)

- **D-04:** Минимум **800 слов** на страницу — это требование v1 и оно осмысленно для SEO. Цель — не «нагон слов», а полезный контент. Если по какой-то услуге органично выходит 600 слов — добивать общими блоками («наш подход», «как мы работаем»), но не водой.

### `/pricing/` — отдельная страница

- **D-08:** Делаем **отдельную `/pricing/`**, не блок в `/about/values/`. Причины:
  - Это популярный поисковый запрос («сколько стоит организация корпоратива калининград», «цена ивент-агентства»)
  - На неё можно ссылаться с каждой страницы услуги
  - Она работает как trust-сигнал (прозрачность)

- **D-09:** Структура `/pricing/`:
  - H1: «Сколько стоит организовать мероприятие в Калининграде»
  - Лид: «Прозрачная агентская модель: 10% от сметы»
  - Блок 1: Из чего складывается смета (площадка, кейтеринг, декор, техника, артисты, координация — реальные расходы на подрядчиков)
  - Блок 2: Что такое 10% агентских (наша зона ответственности — что покупаешь за эти 10%)
  - Блок 3: Типичные диапазоны бюджетов (500 тыс — 1.5 млн / до 7 млн в крупных проектах)
  - Блок 4: Почему нет пакетов «базовый/стандарт/премиум» (каждое событие индивидуально)
  - Блок 5: Какие случаи к нам подходят (минимальный бюджет, специфика)
  - CTA с формой

### JSON-LD Service-schema

- **D-10:** На каждой странице `/services/<slug>/` рендерим `Service` schema через JSON-LD:
  ```json
  {
    "@type": "Service",
    "@id": "https://крылья.life/services/corporate-parties/#service",
    "name": "Организация корпоративных праздников",
    "provider": { "@id": "https://крылья.life/#organization" },
    "areaServed": { "@type": "AdministrativeArea", "name": "Калининградская область" },
    "serviceType": "Корпоративные мероприятия",
    "offers": {
      "@type": "Offer",
      "priceSpecification": {
        "@type": "PriceSpecification",
        "priceCurrency": "RUB",
        "minPrice": 50000,
        "description": "От 10% сметы мероприятия"
      }
    }
  }
  ```

- **D-11:** На каждой подстранице услуги — также `BreadcrumbList`:
  ```
  Главная → Услуги → Корпоративные праздники
  ```

# Phase 4 — Семантическое ядро (гипотеза)

**Дата:** 2026-04-26
**Статус:** Гипотеза. Проверка частотностей через Wordstat — в Phase 7 перед релизом.
**Метод:** общеотраслевые знания + структура запросов B2B-ивент рынка РФ + правила Яндекса по региональной выдаче.

---

## Принципы

- **Сегмент C** (иногородние/федеральные клиенты) — главный для SEO. Они ищут «**в Калининграде**», потому что не знают локальных подрядчиков. Локальные клиенты ищут реже через поиск, чаще приходят по сарафану.
- **«Калининград» в каждом ключе** — обязательно. Без региональной привязки конкурируем со всей Россией, что бесперспективно.
- **Коммерческий интент** > информационный. На главной и на /services/ ставим коммерческие ключи (ищет, кто хочет купить услугу), не информационные («что такое тимбилдинг»).
- **Длинный хвост важнее ВЧ.** «Организация корпоратива в Калининграде» (СЧ, ~100-300 показов/мес) реалистичнее достичь, чем «корпоратив» (ВЧ, тысячи показов, но конкуренция федеральная).

## Что проверить через Wordstat в Phase 7

Перед релизом пройтись по этому файлу через https://wordstat.yandex.ru с регионом «Калининградская область» и:

1. **Проверить реальные частотности** — отметить HIGH / MED / LOW по факту, не по гипотезе
2. **Найти неочевидные синонимы** — Wordstat в правой колонке показывает, что ещё ищут люди, которые искали наш ключ. Может появиться «event-агентство в калининграде» как более частый вариант, или «организация праздников калининград» (без «мероприятий»)
3. **Проверить сезонность** для НГ/летнего корпоратива — Wordstat → «История запросов»
4. **Удалить пустые ключи** (если показывается 0) — не тратить на них релевантность
5. **Расширить хвостами** — низкочастотные «организация корпоратива на 100 человек калининград», «корпоратив для it-компании калининград», «корпоратив на природе калининград»

После Wordstat — обновить тексты, если обнаружим что популярные ключи отличаются от наших гипотез.

## Антиключи (НЕ оптимизируемся)

- «свадьба», «свадебное агентство» — мы не свадебники, не нужно вводить в заблуждение и привлекать нерелевантный трафик
- «детский праздник», «аниматор» — другая ценовая ниша, не наш сегмент
- «прокат техники», «оборудование для мероприятий» — это услуги подрядчиков, не наша зона
- «фотограф калининград», «ведущий калининград» — те же подрядчики, не мы
- «банкетный зал калининград» — услуга площадок, не наша
- ВЧ-федералы без региона («ивент-агентство», «организация мероприятий» — без Калининграда) — не лезем

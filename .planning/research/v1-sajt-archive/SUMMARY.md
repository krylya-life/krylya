# Project Research Summary — крылья.life

**Project:** Сайт ивент-агентства «Крылья» (крылья.life) + SEO + SMM
**Domain:** Content-heavy SEO-маркетинговый сайт на кириллическом IDN-домене для регионального B2B (ивент, Калининград, премиум-сегмент, сегмент C — иногородние/федеральные клиенты)
**Researched:** 2026-04-23
**Confidence:** HIGH

## Executive Summary

«Крылья» — это не SaaS и не e-commerce, а **региональный B2B-сайт доверия**, где главная задача — снять страх иногороднего маркетолога, который не может физически приехать проверить агентство. Эксперты для такой задачи в 2026 строят **статический content-сайт на Astro 6 + Tailwind v4 + MDX + Content Collections**, хостят на бесплатном commercial-friendly хостинге (**Netlify Free**, НЕ Vercel Hobby — его ToS прямо запрещает «advertising the sale of a product or service»), настраивают SEO под **Яндекс как первичный поисковик** (Вебмастер + Метрика + Яндекс.Бизнес + региональная привязка) и считают успехом не «красивый сайт», а накопление trust-сигналов: 5+ детальных кейсов с цифрами, реальные лица команды, узнаваемые логотипы клиентов, прозрачная 10%-модель и юридические реквизиты ИП на виду.

Рекомендуемый подход — **vertical-slice разработка**: сначала тонкая дизайн-система (2–3 дня), затем главная как сквозной вертикальный срез (неделя: все ключевые блоки работают end-to-end), затем — шаблоны услуг и кейсов, которые на 40% состоят из уже собранных блоков. Контент — в `src/content/` (MDX + Zod-схемы), URL — **латинские slug в путях** (`/services/corporate-parties/`), но **кириллический домен и canonical** (`https://крылья.life/...`) — это повышает CTR в Яндексе и сохраняет узнаваемость бренда.

Главные риски — не технические, а **юридические, лицензионные и временны́е**: (1) дедлайн «первый органический лид к 30 июня 2026» при релизе в середине мая — **на грани возможного** для нового IDN-домена (индексация 2–8 недель, топ-30 — 3–6 месяцев), нужен план B; (2) **шрифт FuturaPT** после переезда с Tilda теряет лицензию платформы — либо покупаем веб-лицензию ParaType (~20–30 тыс ₽), либо заменяем на Jost (OFL); (3) **самореклама в Instagram** после 01.09.2025 — любая цена/призыв к покупке = штраф 4–20 тыс ₽ для ИП за каждый пост; (4) **маркировка рекламы в Telegram** — до конца 2026 без штрафов, с 2027 обязательна через ОРД.

## Key Findings

### Recommended Stack

- **Astro 6.x + Node 22 LTS** — статический SSG, Content Layer 5x быстрее Markdown
- **Tailwind CSS v4 (`@tailwindcss/vite`)** — CSS-first, НЕ deprecated `@astrojs/tailwind`
- **MDX + Content Collections + Zod** — 20+ страниц как типизированный источник правды
- **Netlify Free + Netlify Forms + Netlify Functions** — commercial-friendly (Vercel Hobby отпадает по ToS), формы из коробки, Telegram-webhook отдельной функцией
- **Яндекс.Метрика** (deferred через `requestIdleCallback`) + `astro-seo-schema` для JSON-LD LocalBusiness

### Expected Features

**Must have (P1, v1 к релизу 15 мая):**
- Hero с геопривязкой «в Калининграде» + CTA + форма выше сгиба
- Витрина услуг + 6 SEO-подстраниц (корпоративы, деловые, клиентские, тимбилдинги, координация, частные)
- Витрина кейсов + **минимум 5 проработанных кейсов** (задача → решение → цифры → фото → отзыв)
- «О нас» + «Команда» с **реальными фото** (не stock)
- Короткая форма (имя/телефон/описание) с альтернативными каналами (TG/WA/телефон/email)
- Прозрачная **10%-модель** как отдельный блок/страница
- Отзывы с именем, должностью, компанией
- Логотипы клиентов с письменного согласия
- SEO-базис: title/description/H1-H3/alt/canonical/sitemap/robots + JSON-LD LocalBusiness + микроразметка через itemscope/itemprop для Яндекса
- Яндекс.Метрика + цели
- Политика обработки ПДн + чекбокс согласия (152-ФЗ)
- Блок «Почему иногородним»

**Should have (P2, v1.x до 30 июня):** PDF-презентация; блок «Наш тайминг»; CTA «Получить смету за 1 день»; 6–10 кейсов.

**Defer (P3, v2+):** блог; Яндекс.Директ; Calendly; английская версия; видео-кейсы; фотоархив.

**Anti-features:** онлайн-калькулятор, чат-виджет, попапы по таймеру, stock-фото, фиксированные цены «от N», рейтинги/звёзды, новости агентства, видео-бэкграунд в hero.

### Architecture Approach

- **Трёхуровневая layout-композиция:** BaseLayout → ServiceLayout/CaseLayout → страницы
- **Контент отделён от презентации:** MDX в `src/content/`, страницы в `src/pages/` только композируют блоки
- **4 Content Collections** с Zod + references: services, cases, testimonials, team
- **Site-wide константы** в `src/config/`: contacts.ts, site.ts, business.ts, nav.ts
- **Формы:** Netlify Forms (email) + Netlify Function `notify-telegram.ts` (Telegram), токены в env Netlify
- **SEO:** один `<Seo>` компонент + JSON-LD @graph с LocalBusiness как `@id`-entity

### Critical Pitfalls

1. **Нарушение лицензии FuturaPT** после переезда с Tilda. Решение: купить ParaType (~20–30 тыс ₽) ИЛИ Jost (OFL, бесплатный). Demetriss → SVG-логотип. **Блокирует старт вёрстки.**
2. **Нереалистичные сроки индексации** — IDN-домен: 2–8 недель индекса, 3–6 мес топ-30. Дедлайн 30 июня требует **параллельного плана B**.
3. **301-редиректы с Tilda** — внешние ссылки (2ГИС, партнёры, email) ломаются. Выгрузить все Tilda-URL до отключения + `_redirects` в Netlify.
4. **Тонкий контент** — 20 страниц по 200–400 слов = «контентная ферма», навсегда ниже топ-50. Правило: ≥800 слов/страница, 30% уникальной фактуры.
5. **Самореклама в Instagram после 01.09.2025** — любая цена/призыв = штраф 4–20 тыс ₽ для ИП **за каждый пост**. Контент-фильтр, ссылка в bio (не в тексте поста).
6. **Маркировка в Telegram** — до конца 2026 мораторий ФАС, с 2027 обязательна через ОРД + erid. Стратегия-1: «информирование» без CTA → не реклама → без маркировки.
7. **Игнор Яндекса в пользу Google** — Вебмастер + регион Калининград + Яндекс.Бизнес + Метрика первичны. JSON-LD Яндекс в сниппетах не использует → **микроразметка** для Organization/LocalBusiness/Breadcrumb.

## Resolved Conflicts

### Конфликт 1: Vercel vs Netlify (HIGH — юридический)

**Резолюция: Netlify Free побеждает.** Это **не предпочтение, а ToS-ограничение** — Vercel вправе заблокировать проект коммерческого ивент-агентства с рекламой услуг. Netlify явно разрешает commercial use, имеет встроенные Netlify Forms, Netlify Functions, встроенные redirects и native Astro adapter. **Обязательное обновление PROJECT.md.**

### Конфликт 2: Canonical — кириллица vs Punycode (HIGH — SEO)

**Резолюция: Кириллица для видимого слоя, Punycode только для технического.** Яндекс нативно обрабатывает IDN и отображает кириллические URL в сниппетах → выше CTR. Пользователи в Яндекс-выдаче ожидают видеть кириллический домен.

- `astro.config.mjs`: `site: 'https://крылья.life'`
- `<link rel="canonical">` + sitemap.xml + внутренние `<a href>` = **кириллица**
- `robots.txt` (Host / Sitemap директивы) = **Punycode** (Яндекс официально требует)
- TLS CN, SMTP-заголовки = Punycode
- Яндекс.Вебмастер + GSC: регистрируем обе формы, главное зеркало — кириллица

### Конфликт 3: Latin vs Cyrillic slugs (MEDIUM)

**Резолюция: Latin slugs в путях, кириллический домен.** `/services/corporate-parties/` — чище для sharing, нет encoding-tax. Slug живёт в frontmatter коллекции, не выводится из filename.

### Конфликт 4: JSON-LD vs микроразметка (LOW-MEDIUM)

**Резолюция: делаем ОБА формата.**
- JSON-LD @graph в `<head>` через `<Seo>` — для Google (LocalBusiness/Organization/Service/Event/BreadcrumbList)
- Микроразметка через `itemscope`/`itemprop` — для Яндекс-критичных типов: Organization + LocalBusiness (футер), BreadcrumbList (компонент), PostalAddress (/contacts/)

### Конфликт 5: Таймлайн дедлайна 30 июня (HIGH — roadmap)

**Резолюция: дедлайн не меняем, план B — отдельная параллельная фаза.** Запускается одновременно с релизом:
- Яндекс.Бизнес с полной карточкой (заявки через виджет Карт до индексации сайта)
- Активный Telegram-канал с ссылками на сайт
- Ручной «Переобход страниц» в Вебмастере (20 URL/день)
- 2–3 гостевых упоминания в региональных VK/тг-пабликах

## 1. SEO-контент: что приводит органику в B2B-ивенте

### Рабочие типы контента (с примерами)

Исследование SEO-кейса We Event (polza-agency.ru) и практик мировых агентств (seotakeoff.com) показывает: органику в ивент-нише генерирует не «блог ради блога», а контент с чёткой коммерческой или информационной интентой.

**Высокоэффективные форматы:**

| Тип контента | Почему работает | Пример темы | Сложность |
|---|---|---|---|
| Страницы-посадочные под интент | Прямое попадание в коммерческий запрос | «Корпоратив под ключ Калининград», «Тимбилдинг для застройщиков» | LOW |
| Кейсы (задача → решение → цифры) | Конвертируют читателя в заявку; занимают информационные + коммерческие запросы | «Как мы организовали Day-1 для 500 гостей ЖК...» | MEDIUM |
| «Сколько стоит» / ценовые гайды | Снимают возражение «непонятно бюджет» на входе | «Сколько стоит организовать корпоратив в Калининграде» | LOW |
| «Как организовать X» — пошаговые гайды | Информационный трафик → прогрев → лид | «Как выбрать площадку для корпоратива в Калининграде» | LOW |
| Чек-листы и шаблоны | Ранжируются по информационным запросам, дают backlinking | «Чек-лист подготовки корпоратива за 3 месяца» | LOW |
| Отраслевые статьи под сегмент | Цепляют узкую ЦА, выделяют экспертизу | «Мероприятия для застройщиков: 5 форматов, которые продают жильё» | MEDIUM |
| Тренд-статьи | Информационный трафик + цитируемость | «Тренды корпоративных мероприятий 2026» | LOW |
| Сравнительные материалы | Конкурентная семантика с коммерческой интентой | «Корпоратив в ресторане vs выездной: что выбрать» | MEDIUM |

**Что НЕ работает в B2B-ивент-нише:**
- Нейтральные новостные посты «провели мероприятие» без цифр и SEO-оптимизации
- Абстрактные обзоры без привязки к локации
- Контент «о нас» вместо контента «для вас»

### Структура статьи, которая ранжируется

На основе практик seotakeoff.com и российских SEO-кейсов:

```
1. Заголовок H1 с ключевым словом + локацией («Как организовать корпоратив в Калининграде: гайд 2026»)
2. Быстрый ответ / summary (2-3 предложения) — для сниппетов Яндекса
3. Оглавление с якорями (для длинных материалов от 1 500 слов)
4. Пошаговый контент / советы / кейс
5. Локальные примеры (площадки, подрядчики — сигнал локальной релевантности)
6. FAQ блок (под голосовой поиск и расширенные сниппеты)
7. CTA — «Получить консультацию» / «Обсудить формат»
8. Перелинковка на услуги и другие статьи
```

Длина: 1 200–1 800 слов для информационных статей; кейсы могут быть короче (800–1 000) если плотный.

### Рубрикатор контент-хаба для «Крыльев»

Предложенные рубрики (от приоритетных к вторичным):

| Рубрика | Тип интенты | Примеры тем |
|---|---|---|
| Форматы мероприятий | Информационная + коммерческая | «Что такое иммерсивный корпоратив», «Тимбилдинг для застройщиков» |
| Как организовать | Информационная | «Сколько стоит», «Как выбрать площадку», «За сколько готовить» |
| Кейсы / портфолио | Коммерческая | Разбор каждого реального проекта |
| Калининград для бизнеса | Локальная + информационная | «Топ-10 площадок для корпоратива в Калининграде», «Выездной из Москвы» |
| Тренды | Информационная | Ежегодные обзоры трендов |
| Отрасли | Сегментная коммерческая | «Ивенты для девелоперов», «Мероприятия для ритейла» |

## 3. SMM-форматы для ивент-агентства в 2026

### Контекст ограничений (HIGH confidence)

С 01.09.2025 в Instagram запрещена любая реклама (в т.ч. самореклама): штраф 4–20 тыс ₽/пост для ИП. Telegram — мораторий ФАС на требование erid до конца 2026. Стратегия: **режим «информирования»** — контент без цен, без CTA «оставьте заявку», без оценочных прилагательных.

### Платформы в 2026 (Россия)

По данным elama.ru и Likeni 2025: Telegram занимает 1-е место по охватам у бизнесов; Instagram сохраняет высокую лояльную аудиторию, но без возможности платного продвижения.

| Платформа | Роль | Контент | Особенность |
|---|---|---|---|
| Instagram | Канал первого контакта, визитка | Reels, карусели, Сторис | Без цен/CTA; алгоритм смотрит watch-time и reshares |
| Telegram | Основной продающий канал | Тексты, фото-подборки, лонгриды, опросы | Без erid до конца 2026; прямое попадание в ленту без алгоритма |
| Сайт-блог | Долгосрочный SEO-актив | Статьи 1 200–1 800 слов | Перелинковка из соцсетей на сайт = воронка |

### Instagram Reels — рабочие паттерны 2026

На основе designlumo.com, sproutsocial.com, cloudcampaign.com:

| Формат Reels | Описание | Применение для «Крыльев» | Длина |
|---|---|---|---|
| **Закулисье (BTS)** | Монтаж: хаос до → красота во время → аплодисменты после | Монтаж/декор за 4 часа до старта → готовый зал | 15–30 сек |
| **Трансформация** | «До и после» площадки, декора, пространства | Пустой зал → оформленный корпоратив | 10–20 сек |
| **Мини-серия (3 части)** | 3 коротких Reel, вышедших за 3 дня — раскрывают один ивент | Подготовка → ивент → реакция гостей | по 15 сек |
| **Процесс + результат** | 15-секундный «как это делается» с оверлей-текстом | Как мы упаковываем подарки гостям / оформляем зону регистрации | 15 сек |
| **Кейс-ролик** | Нарративный ролик: задача → формат → реакция | История одного мероприятия без цифр (под 38-ФЗ) | 30–60 сек |
| **Экспертный тезис** | «Один инсайт» от организатора поверх красивого видеоряда | «Почему тимбилдинг на природе провалится, если нет…» | 15–30 сек |
| **Trend-jacking** | Популярный аудио/мем-тренд + ивент-контент | Под трендовый звук — подборка моментов корпоратива | 10–15 сек |

**Алгоритм Instagram 2026 наказывает:** ленивые stock-кадры, логотипы на весь экран, слабые первые 2 секунды.

**Алгоритм награждает:** watch-time > 80%, reshares, первый комментарий в течение 10 минут.

**Частота постинга:** 3–4 Reels в неделю (оптимум по данным cloudcampaign.com).

| Формат | Пример поста | Для чего |

### Контент-фильтр под 38-ФЗ (5 вопросов)

Перед публикацией любого поста:
1. Есть ли цена или скидка? → убрать
2. Есть ли CTA «позвоните», «оставьте заявку», «купите»? → убрать
3. Есть ли оценочные прилагательные «лучший», «уникальный», «профессиональный»? → убрать или переформулировать на факт
4. Указывает ли пост на сравнение с конкурентами? → убрать
5. Создаёт ли пост срочность «только до...», «акция»? → убрать

## 4. Партнёрские модели: локальное агентство ↔ федеральные игроки

### Как федеральные агентства выбирают локальных партнёров

На основе event.ru (Avantage Event Project — 6 правил), Eventum Premo, AKAR-рейтинга:

**Что критично для федерального агентства при выборе регионального партнёра:**

| Критерий | Что искать/показывать |
|---|---|
| Доказанный опыт в регионе | Кейсы с именами площадок, локальных подрядчиков, цифрами гостей |
| Надёжность и пунктуальность | Отзывы от предыдущих партнёров; история без «провалов» |
| Знание локальных площадок | Наличие нескольких проверенных площадок под разные бюджеты и форматы |
| База подрядчиков | Свои проверенные технари, декораторы, кейтеринг, ведущие в регионе |
| Финансовая прозрачность | Готовность к агентскому вознаграждению без скрытых наценок; работа по договору |
| Коммуникация | Быстрый ответ, понятная отчётность, профессиональная переписка |
| Публичное присутствие | Сайт + соцсети = «проверка» перед звонком (ключевое для «Крыльев») |

**Процесс попадания в субподрядную цепочку:**
1. Федеральное агентство получает проект в регионе → ищет локального партнёра в отраслевых каналах (event.ru каталог, eventcatalog.ru, рекомендации коллег)
2. Проверяет сайт + соцсети кандидата
3. Проводит онлайн-встречу (брифинг)
4. Первый проект — «тест»: небольшой или параллельный проект для проверки качества

**Вывод для «Крыльев»:** сайт + кейсы + Instagram/Telegram — буквально «входной билет» в субподрядную цепочку. Без публичного присутствия попадания не будет.

### Модели партнёрства с застройщиками

| Модель | Описание | Как выйти |
|---|---|---|
| Постоянный ивент-подрядчик | Застройщик без внутренней ивент-команды отдаёт все мероприятия агентству на подряд | Аутрич к директору по маркетингу |
| Пакетный годовой контракт | Агентство выигрывает тендер на «ивент-программу года» (8–12 мероприятий) | Участие в закупках или прямое предложение с портфолио |
| Партнёр к конкретному объекту | Открытие ЖК → агентство ведёт все ивенты вокруг этого объекта | Выход через PR-директора застройщика |

## 5. B2B-аутрич: как выходить на крупных клиентов и партнёров

### Что работает в B2B-ивент-аутриче (MEDIUM confidence — российский рынок)

**Особенности цикла сделки в B2B-ивенте:**
- Цикл: 2–6 месяцев от первого касания до договора
- ЛПР: директор по маркетингу (застройщики, ритейл), HR-директор (корпоративы), исполнительный директор (малый бизнес)
- Первое касание не продаёт — оно «снимает тревогу»

**Форматы первого касания (от эффективного к менее):**

| Канал | Формат | Рекомендация |
|---|---|---|
| Email-аутрич | Персонализированное письмо с конкретным релевантным кейсом | Открывать с «триггера»: «заметил, что у вас в апреле открытие объекта X» |
| LinkedIn / личный профиль | Запрос в контакты + персонализированное сообщение | Сначала комментарий к публикации, потом запрос |
| Тёплый звонок после email | Следующий шаг через 3–5 дней после письма | Цель — не продать, а договориться на встречу |
| Отраслевые события | Конференции застройщиков, HR-форумы, ивент-тусовки | Живой контакт = ускорение цикла в 3–5 раз |
| Рекомендация / реферал | Через текущего клиента → к новому | Самый тёплый лид; работает лучше всего |

**Структура первого письма (что работает по данным HubSpot, Respona, Clay):**
```
1. Персонализированный хук (1 предложение) — конкретный факт о компании
2. Релевантный кейс (1–2 предложения) — что делали похожего
3. Конкретная ценность (1 предложение) — что предлагаем конкретно
4. Мягкий CTA (1 вопрос) — «Имеет смысл поговорить?»
Длина: до 100 слов
```

**Что НЕ работает:**
- Длинные письма с описанием агентства и списком услуг
- «Мы лучшие в своей области» без доказательств
- Массовая рассылка без персонализации
- CTA «позвоните нам» в первом письме

### Упаковка оффера «Локальный партнёр» для «Крыльев»

На основе Eventum Premo, event.ru-практик:

**Что хочет видеть федеральный клиент/партнёр:**

| Элемент | Формат | Пример для «Крыльев» |
|---|---|---|
| Доказательство локальности | Список площадок + кейсы | «5 площадок Калининграда от 80 до 500 гостей — мы работали с каждой» |
| Опыт в масштабе | Цифры: самый большой проект, кол-во гостей | «200+ мероприятий, крупнейшее — День металлурга ГРК Быстринское» |
| Под ключ без головной боли | Что берём на себя | «Площадка, техника, декор, кейтеринг, логистика, трансфер, отчёт» |
| Локальная база подрядчиков | Проверенные партнёры | «Своя база из 20+ проверенных подрядчиков — технари, декораторы, кейтеринг» |
| Прозрачная модель | 10% агентских | «Агентское вознаграждение 10% от сметы — без скрытых наценок на подрядчиков» |
| Процесс работы | Схема из 5–6 шагов | «Бриф → концепция (3 дня) → смета → договор → реализация → отчёт» |
| Скорость реакции | SLA | «Первый ответ в течение 2 часов» |

**Оффер-заголовок:** «Ивент-агентство «Крылья» — ваш локальный партнёр под ключ в Калининграде. Мы знаем все площадки, всех подрядчиков и все нюансы региона».

### Anti-Features (то, что кажется хорошей идеей, но навредит)

| Feature | Why Requested | Why Problematic | Alternative |
|---|---|---|---|
| Онлайн-калькулятор стоимости | Клиент хочет «прикинуть бюджет» | Ломает премиум-позиционирование; каждый проект уникален; занижает ожидания | Страница «Как мы считаем стоимость» с объяснением 10%-модели |
| Прайс-лист на сайте | Прозрачность | Отпугивает иногородних крупных клиентов (бюджет не сопоставим с ценами калининградского рынка); мешает позиционированию «под ключ» | «Бюджет обсуждаем на брифинге» + примеры из кейсов |
| Рейтинги-звёзды / виджет отзывов | Социальное доказательство | В B2B-ивенте звёзды ассоциируются с агрегаторами, не с бутиковым агентством | Именные текстовые отзывы с должностью/компанией |
| Чат-виджет / онлайн-чат | Снизить барьер входа | Создаёт ожидание мгновенного ответа 24/7; нарушает premium-ощущение | Форма заявки с обещанием ответа за 2 часа |
| Попап по таймеру / exit-intent | Захват лидов | В B2B ничего не раздражает корпоративного клиента сильнее; сигнализирует об отчаянии | Ненавязчивый блок формы в конце страницы |
| Stock-фото в кейсах | Нет своих фото | Мгновенно разрушает доверие; клиент видит, что это не реальная работа | Хотя бы 3–5 живых фото с любого мероприятия |
| Массовая SMM-рассылка по базе без персонализации | Охватить больше | В B2B ивенте воспринимается как спам; портит репутацию | Персонализированный аутрич к 20–30 целевым контактам |
| Английская версия сайта | «Для иностранных клиентов» | 100% клиентов русскоязычные; разработка/поддержка = лишние расходы | Один качественный русский сайт |
| Агрессивный CTA в Instagram | «Максимизировать конверсию» | Штраф 4–20 тыс ₽/пост по 38-ФЗ | Режим информирования; ссылка в bio |

## Feature Dependencies

```
SEO-контент (блог/статьи)
    └──requires──> Контент-хаб на сайте (Astro Collection или внешний инструмент)
                       └──requires──> Семантическое ядро 2.0 (кластеры + рубрикатор)

Аутрич к федеральным партнёрам
    └──requires──> Кейсы с цифрами на сайте (портфолио)
    └──requires──> Презентация-оффер (PDF/Canva)

Линейка форматов мероприятий
    └──enhances──> SEO-страницы под форматы (каждый формат = посадочная)
    └──enhances──> SMM-контент (каждый формат = отдельная Reels/серия)
    └──enhances──> Аутрич к клиентам (оффер под сегмент)

SMM-Telegram-контент
    └──enhances──> Аутрич (партнёр смотрит канал перед встречей)
    └──conflicts──> 38-ФЗ (запрет на рекламу в Instagram)

Страницы под сегменты (девелоперы, иногородние)
    └──requires──> Семантическое ядро (запросы сегмента C)
    └──enhances──> Конверсия аутрич-писем (ссылка на релевантную страницу)
```

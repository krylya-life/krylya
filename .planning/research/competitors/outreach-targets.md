# Целевые компании для аутрича (вход в Фазу 15)

Отдельный список потенциальных партнёров, отобранных из `competitor-ru.md` по
тегу **«потенциальный партнёр»** (D-11). Это прямой вход в Фазу 15 / PARTNER-01:
позиционировать «Крылья» как надёжного **локального подрядчика в Калининграде**
для проектов, которые федеральные агентства ведут в регионе.

**Логика:** лобовая конкуренция с федералами по масштабу проигрышна. Выигрыш —
локальная экспертиза. Крупное агентство берёт проект «сверху», а локальную часть
(площадки, подрядчики, логистика на месте) всё равно кому-то отдаёт — «Крылья»
и есть эта опора в анклаве.

**152-ФЗ:** ниже — **только публично опубликованные контакты** (корпоративные
сайты и формы). Персональные контакты сотрудников (личные телефоны, почты ЛПР)
здесь не приводятся; их сбор — задача самой Фазы 15 через публичные каналы.

Приоритет аутрича проставлен по потенциалу кооперации из матрицы `competitor-ru.md`.

---

## Высокий приоритет

### Авантаж (Avantage Event Project)
- **Публичный контакт:** сайт avantage.ru (форма обратной связи на сайте), ВКонтакте
- **Специализация:** крупные корпоративные мероприятия, конференции, форумы, тимбилдинг; федеральные клиенты (Сбер, Росатом, X5)
- **Потенциал сотрудничества:** декларируют работу по всей России через субподрядчиков — прямой кандидат отдать «Крыльям» локальную реализацию проектов, идущих в Калининград

### Мастерская Событий (Eventum Premo)
- **Публичный контакт:** сайт eventumpremo.ru (форма на сайте), ВКонтакте, Telegram-канал
- **Специализация:** топ федеральных рейтингов, full-service корпоративные ивенты, деловые события; технически сильный сайт
- **Потенциал сотрудничества:** федеральные клиенты, нет своей команды в Калининграде — «Крылья» закрывают локальную часть (форумы по туризму, приграничная тематика, гос-корпоративные ивенты)

## Средний приоритет

### ESM Group (Event Service Management)
- **Публичный контакт:** сайт esmgroup.ru (форма на сайте), ВКонтакте, Telegram
- **Специализация:** полный цикл, работа под фиксированный бюджет, корпоративный сегмент — позиционирование, близкое к «Крыльям»
- **Потенциал сотрудничества:** близкая модель работы облегчает стыковку процессов; кандидат на субподряд по калининградским проектам

### Red Jolly
- **Публичный контакт:** сайт redjolly.ru (форма на сайте), ВКонтакте, Telegram
- **Специализация:** B2B-ниша, деловые ивенты
- **Потенциал сотрудничества:** Калининград как выездное направление для их деловых мероприятий — «Крылья» как локальный исполнитель

## Низкий приоритет (кооперация только под конкретный запрос)

### Event Rocks
- **Публичный контакт:** сайт eventrocks.ru (форма на сайте), ВКонтакте
- **Специализация:** корпоративные и нестандартные форматы
- **Потенциал сотрудничества:** субподрядная кооперация точечно, при конкретном калининградском проекте

### Brownfield Agency
- **Публичный контакт:** сайт brownfield.ru (форма на сайте), ВКонтакте, Instagram
- **Специализация:** нишевые арт/культурные проекты
- **Потенциал сотрудничества:** низкий — специализация расходится с корпоративным фокусом «Крыльев»; держать в поле зрения на случай культурного события в регионе

### BBDO Events
- **Публичный контакт:** сайт bbdoevents.ru (входит в международную структуру)
- **Специализация:** крупные международные корпоративные ивенты
- **Потенциал сотрудничества:** двойной тег (конкурент/партнёр); аутрич маловероятен из-за разницы масштаба — режим **мониторинга**: если кто-то из их клиентов выходит в Калининград, появляется точка входа

# Крылья — сайт и цифровое присутствие

## What This Is

Проект по превращению цифрового присутствия ивент-агентства «Крылья» (Калининград) в работающий канал привлечения заявок из поиска и соцсетей. Закрывает три блока сразу: **новый сайт** (переезд с Tilda на Astro 6 + Netlify с чистой переделкой дизайна), **SEO-запуск** (индексация через Яндекс-экосистему, семантика, первичная оптимизация) и **SMM-план** (разовая стратегия + контент-календарь для Telegram и Instagram строго на узнаваемость). Основная аудитория — иногородние и федеральные клиенты (сегмент C из бизнес-контекста), которые ищут ивент-агентство в Калининграде через Яндекс и Google.

## Core Value

**Один реальный контракт, пришедший через органический поиск на сайт к 30 июня 2026.** Всё остальное — способы этого добиться. Если к дедлайну приходит хотя бы одна заявка из поиска, доведённая до договора, проект считается успешным; если нет — даже идеальный дизайн и сотни постов в SMM не спасут.

### Out of Scope

<!-- Explicit boundaries. Includes reasoning to prevent re-adding. -->

- **Яндекс.Директ и платный трафик** — отложено в v2 (после 30 июня 2026). Сначала проверяем, что сайт конвертирует органический трафик; платный запускать на непроверенной воронке = сливать бюджет
- **Фотоархив / систематизация фотографий с мероприятий** — на паузе по решению Марии (23 апреля 2026). Подключим в следующем цикле, после сайта и SMM
- **Блог со статьями** — заложен в sitemap как «вторая итерация», в v1 не включаем. Приоритет — страницы услуг и кейсы
- **Мобильное приложение, CRM, личный кабинет клиента** — не нужно бизнес-модели. Заявки приходят на email и в Telegram, дальше работа оффлайн
- **Английская версия сайта** — 100% клиентов русскоязычные, нет запроса
- **Переезд на WordPress** — рассмотрен и отвергнут в пользу Astro + Netlify: меньше технической нагрузки, бесплатный хостинг, полная автоматизация через Claude
- **Деплой на Vercel Free** — рассмотрен и отвергнут: Vercel Fair Use Guidelines прямо запрещают «advertising the sale of a product or service» на Hobby tier, что делает его юридически непригодным для коммерческого сайта ивент-агентства. Выбран Netlify Free
- **Визуально-идентичный клон текущего Tilda-сайта** — отвергнут. Мария сама оценила текущий сайт как «чиповые работы»; копировать несимпатичное бессмысленно. Tilda — референс структуры, дизайн переделываем чище
- **Лицензия на FuturaPT** — отклонена в пользу бесплатного Jost (OFL). Решение от 23 апреля 2026. Jost геометрически близок к FuturaPT, для читателя разница незаметна, экономия ~20–30 тыс ₽
- **Онлайн-калькулятор стоимости** — ломает премиум-позиционирование, упрощает сложное (каждый корпоратив индивидуален). В ивент-нише это anti-feature
- **Чат-виджеты, попапы по таймеру, stock-фото, рейтинги-звёзды** — anti-features, подтверждённые в research FEATURES.md
- **GA4** — не ставим. Целевая аудитория сегмента C ищет в Яндексе; в РФ для B2B-ивента 70%+ трафика из Яндекса. GA4 даст шум без ценности

## Context

**Бизнес-контекст:** Агентство «Крылья» работает по модели 10% агентских от сметы мероприятия. Средний чек заказчика — 500 тыс – 1,5 млн ₽; выручка агентства с проекта — 50–150 тыс ₽. Факт 2025: 15–18 проектов, ~18 млн ₽ суммарно. Цель на 2026 — 700 тыс ₽/мес чистыми, для чего бизнесу нужен канал сайт + поиск. Полный бизнес-контекст — в [../.business/INDEX.md](../.business/INDEX.md), выжимка под сайт — в [../brief.md](../brief.md).

**Юридические реквизиты** (утверждены для публикации в футере, 23 апреля 2026): ИП Вострикова Мария Валерьевна, ИНН 550209075500, ОГРНИП 324390000038348. Telegram заявок — @mashavostrik (личный). Подробнее — в [../.business/company/legal.md](../.business/company/legal.md).

**Целевая аудитория сайта:** три сегмента, но приоритет — сегмент C (иногородние и федеральные клиенты). Именно они ищут ивент-агентство в Калининграде через поиск, не зная локальных подрядчиков. Сегменты A (девелоперы) и B (местный крупный бизнес) приходят через сарафан; для них сайт — «визитка для проверки», вторичная роль.

**Главный месседж:** «Надёжный партнёр под ключ в Калининграде» — надёжность и локальная экспертиза первичны, креатив и цена вторичны. Три смысловых опоры в порядке важности: надёжность → локальная экспертиза → креатив.

**Текущее состояние сайта:** крылья.life работает на Tilda Personal, задеплоен, но не проиндексирован ни в одном поисковике, SEO не проводилось. Есть черновики текстов в [../content/pages/](../content/pages/) — драфт, сверка с реальным сайтом обязательна в Phase 0. Карта сайта в [../sitemap.md](../sitemap.md): 18–23 SEO-страницы. Семантическое ядро не собрано (ресёрч в начале Phase 4). Кейсы в [../content/cases/](../content/cases/) — только шаблон.

**Брендбук:** монохром + жёлтый акцент `#FFF200`, шрифты **Jost** вместо FuturaPT (решение от 23.04.2026: бесплатный OFL, геометрически близок) и Demetriss (акцидентный — только в SVG-логотипе, как веб-шрифт не подключаем). Исходники — в `~/Documents/Крылья. Общее./Айдентика/`. Описание — [../.business/assets/brand-guidelines.md](../.business/assets/brand-guidelines.md).

**Согласия:** команда (Маша, Кристина, координаторы) — согласие на публикацию фото/имени/должности есть. Клиенты — условия договора позволяют публикацию фото с мероприятий. Статус публикации **имён и отзывов** по конкретным клиентам (ГРК «Быстринское», ЖК «ВКЛЮЧИ», «ДОМ», «Нити дочерей ночи») уточняется в Phase 0 — разные кейсы могут потребовать отдельного согласия.

**Риск-профиль и план B:** исследование показало, что первая заявка из поиска на новом кириллическом IDN-домене реалистично появляется через 3–6 месяцев индексации. Релиз 15 мая + дедлайн 30 июня = ~6 недель — **нижняя граница возможного**. Поэтому план B (Яндекс.Бизнес + TG + ручной переобход + гостевые упоминания) включён как штатная параллельная фаза, не «если не получится».

**Ключевое ограничение по SMM:** в РФ Instagram с 01.09.2025 запрещена не только реклама третьих лиц, но и **самореклама** — любые цены, акции, CTA «оставьте заявку» = штраф 4–20 тыс ₽/пост для ИП. Бизнес-аккаунт вести можно, но исключительно в режиме «информирования» без оценочных прилагательных. Telegram — мораторий ФАС на штрафы за маркировку до конца 2026.

**Ресурсы и руки:** Мария ведёт проект и собирает материал по кейсам сама. Кристина и координаторы в проекте сайта напрямую не участвуют. Это значит, что вся техническая часть автоматизирована через Claude — одна из причин ухода с Tilda.

## Constraints

- **Timeline:** Релиз сайта с базовой индексацией — не позже середины мая 2026. Полный скоуп (кейсы + SMM) — до 30 июня 2026. Буфер индексации 6 недель — на грани возможного для нового IDN-домена, отсюда параллельный план B
- **Tech stack:** Astro 6 + Node 22 LTS + Tailwind CSS v4 (`@tailwindcss/vite`) + MDX + Content Collections + Zod. Деплой через Netlify (Free tier), формы через Netlify Forms + Netlify Functions для Telegram-webhook. Репозиторий на GitHub
- **Budget:** Около 0 ₽. Бесплатный хостинг Netlify, бесплатный GitHub, бесплатный Jost (OFL), бесплатные регистрации в вебмастерах. Разовые возможные расходы — только если захотим отдельные платные интеграции, пока не планируем
- **Compatibility:** Сайт работает на кириллическом домене крылья.life (Punycode `xn--j1aco8bgs.life`), у регистратора nic.ru. Canonical + внутренние ссылки + sitemap — в кириллице; Punycode — только в TLS CN, robots.txt (Host/Sitemap) и SMTP-заголовках. Старые URL Tilda закрываются 301-редиректами через `_redirects` Netlify
- **Legal (SMM):** Instagram — только «информирование» без цен, акций и прямых CTA (штраф 4–20 тыс ₽/пост). Telegram — «информирование» без erid до конца 2026. Любой SMM-контент проходит фильтр из 5 вопросов
- **Legal (сайт):** в футере обязательно юрлицо + ИНН + ОГРНИП. На формах — чекбокс согласия на обработку ПДн по 152-ФЗ + ссылка на Политику
- **Resource:** Руки есть только у Марии; все правки контента — через правку Markdown в репозитории и автодеплой Netlify, никаких визуальных конструкторов
- **Dependencies:** Для старта нужны аккаунты GitHub и Netlify (ещё не заведены). Создание — первая задача Фазы 1

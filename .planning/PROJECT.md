# Крылья — сайт и цифровое присутствие

## What This Is

Проект по превращению цифрового присутствия ивент-агентства «Крылья» (Калининград) в работающий канал привлечения заявок из поиска и соцсетей. Закрывает три блока сразу: **новый сайт** (переезд с Tilda на Astro + Vercel с чистой переделкой дизайна), **SEO-запуск** (индексация, семантика, первичная оптимизация) и **SMM-план** (разовая стратегия + контент-календарь для Telegram и Instagram на узнаваемость). Основная аудитория — иногородние и федеральные клиенты (сегмент C из бизнес-контекста), которые ищут ивент-агентство в Калининграде через Яндекс и Google.

## Core Value

**Один реальный контракт, пришедший через органический поиск на сайт к 30 июня 2026.** Всё остальное — способы этого добиться. Если к дедлайну приходит хотя бы одна заявка из поиска, доведённая до договора, проект считается успешным; если нет — даже идеальный дизайн и сотни постов в SMM не спасут.

## Context

**Бизнес-контекст:** Агентство «Крылья» работает по модели 10% агентских от сметы мероприятия. Средний чек заказчика — 500 тыс – 1,5 млн ₽; выручка агентства с проекта — 50–150 тыс ₽. Факт 2025: 15–18 проектов, ~18 млн ₽ суммарно. Цель на 2026 — 700 тыс ₽/мес чистыми, для чего бизнесу нужен канал сайт + поиск, чтобы отвязаться от сарафанного радио. Полный бизнес-контекст — в [../.business/INDEX.md](../.business/INDEX.md), выжимка под сайт — в [../brief.md](../brief.md).

**Целевая аудитория сайта:** три сегмента, но приоритет — сегмент C (иногородние и федеральные клиенты). Именно они ищут ивент-агентство в Калининграде через поиск, не зная локальных подрядчиков. Сегменты A (девелоперы) и B (местный крупный бизнес) приходят через сарафан; для них сайт — «визитка для проверки», вторичная роль.

**Главный месседж:** «Надёжный партнёр под ключ в Калининграде» — надёжность и локальная экспертиза первичны, креатив и цена вторичны. Три смысловых опоры в порядке важности: надёжность → локальная экспертиза → креатив. Полная расшифровка в [../brief.md](../brief.md).

**Текущее состояние сайта:** крылья.life работает на Tilda Personal (задеплоен, но не проиндексирован ни в одном поисковике, SEO-оптимизация не проводилась, сама Мария оценивает как «чиповые работы»). Есть черновики текстов в [../content/pages/](../content/pages/) — скорее драфт, чем финал. Есть карта сайта в [../sitemap.md](../sitemap.md): 18–23 SEO-страницы минимум. Семантическое ядро не собрано. Кейсы в [../content/cases/](../content/cases/) — только шаблон.

**Брендбук:** монохром + жёлтый акцент `#FFF200`, шрифты FuturaPT (основной) и Demetriss (акцидентный). Исходники — в `~/Documents/Крылья. Общее./Айдентика/` (доступ подтверждён). Описание — [../.business/assets/brand-guidelines.md](../.business/assets/brand-guidelines.md).

**Ключевое ограничение по SMM:** в РФ Instagram работает в режиме ограниченной рекламы — закон запрещает указывать цены, акции и призывать к покупке. SMM-план строится исключительно под узнаваемость и личный бренд, трафик ведётся на сайт, где коммерческая коммуникация возможна без ограничений.

**Ресурсы и руки:** Мария ведёт проект и собирает материал по кейсам сама. Кристина (соосновательница) и координаторы в проекте сайта напрямую не участвуют. Это значит, что вся техническая часть должна быть максимально автоматизирована через Claude — одна из причин ухода с Tilda.

## Constraints

- **Timeline:** Релиз сайта с базовой индексацией — не позже середины мая 2026, чтобы дать поисковикам ~6 недель на индексацию до дедлайна 30 июня. Полный скоуп (кейсы + SMM) — до 30 июня 2026
- **Tech stack:** Astro 5 + Tailwind CSS + MDX + Content Collections. Деплой через Vercel (Free tier). Репозиторий на GitHub. Все обоснования — в разделе Key Decisions
- **Budget:** Минимальный. Бесплатный хостинг на Vercel, бесплатный GitHub, бесплатные регистрации в вебмастерах. Потенциальные разовые расходы: лицензия на шрифты FuturaPT (5–8 тыс ₽) или замена на бесплатный аналог
- **Compatibility:** Сайт должен работать на кириллическом домене крылья.life (Punycode `xn--j1aco8bgs.life` — только служебно), существующий у регистратора nic.ru. Старые URL Tilda нужно по возможности сохранить или закрыть 301-редиректами
- **Legal (SMM):** Любые тексты и сценарии для Instagram проходят фильтр закона о рекламе РФ — без цен, без прямых призывов к покупке, без «продающих» офферов
- **Resource:** Руки есть только у Марии; любые задачи, требующие копипастинга или ручной работы в админке, минимизируются — это одно из обоснований выбора стека
- **Dependencies:** Для старта нужны аккаунты GitHub и Vercel (ещё не заведены). Их создание — первая задача Фазы 1

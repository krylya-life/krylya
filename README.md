# krylya/ — проект сайта «Крылья» (крылья.life)

Рабочая папка по сайту ивент-агентства КРЫЛЬЯ (Калининград). Домен — кириллический **крылья.life**. Сайт сделан на Tilda и задеплоен.

## С чего начать

1. Прочитать [CLAUDE.md](CLAUDE.md) — там память проекта и ссылки на бизнес-контекст в `.business/`.
2. Прочитать [brief.md](brief.md) — короткая выжимка «про что сайт и для кого».
3. Посмотреть [sitemap.md](sitemap.md) — какие страницы делаем.
4. Черновики текстов — в [content/pages/](content/pages/).

## Структура

```
krylya/
├── CLAUDE.md              ← память проекта + ссылки на .business/

├── content/

│   └── keywords.md        ← семантическое ядро (в работе)
└── design/                ← референсы, макеты, UI (пусто, наполнять по мере работы)
```

## Важно про стек

Сайт работает на **Tilda** — это конструктор, кода нет. Поэтому в этой папке мы ведём **контент, смыслы, SEO и стратегию**, а не код. Всё, что готовим здесь, переносится в Tilda руками через её редактор.

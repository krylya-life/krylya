# Папка для фотографий и медиа

Сюда складываем фотографии, которые потом попадут на сайт крылья.life. Когда проект переедет на Astro, содержимое этой папки перенесётся в техническую структуру сайта автоматически — Марии думать об этом не надо.

## Что куда класть

### `team/`
Фото команды для страницы «О команде».

Удобнее всего:
- `team/maria.jpg` (или .png / .webp — любой формат)
- `team/kristina.jpg`
- `team/sergey.jpg`

Если фото несколько — выбираем одно лучшее и кладём с именем, как выше. Остальные можно положить в `team/_archive/` — не потеряются.

### `cases/<название-кейса>/`
Фото по каждому мероприятию — одна подпапка на один кейс.

Уже подготовлены папки под известные проекты (можно сразу класть фото):
- `cases/bystrinskoe-den-metallurga/` — День металлурга «ГРК Быстринское» (2023)
- `cases/vklyuchi-partnerskij-vecher/` — ЖК ВКЛЮЧИ, партнёрский вечер
- `cases/vklyuchi-start-prodazh/` — ЖК ВКЛЮЧИ, старт продаж 8 и 9 литера
- `cases/vklyuchi-vydacha-klyuchej/` — ЖК ВКЛЮЧИ, выдача ключей
- `cases/dom-festival/` — Фестиваль современного искусства «ДОМ»
- `cases/niti-docherej-nochi/` — Презентация книги «Нити дочерей ночи»
- `cases/aero-otkrytie/` — Открытие ЖК АЭРО
- `cases/rasscvet-ng-korporativ/` — Новогодний корпоратив девелопера «Расцвет»
- `cases/_prochee/` — всё остальное, что ещё не решили, попадает ли в кейсы

Если появляется новый кейс, которого нет в списке — просто создай папку с понятным названием (латиницей, через дефисы), например `cases/yubiley-60-let/`.

## Форматы и размеры

На этой стадии — любые. Главное, чтобы оригиналы были в высоком качестве. Сжимать и конвертировать в webp будем автоматически, когда будем ставить фото на сайт.

## Имена файлов

Удобнее, когда имя говорит, что на фото. Примеры:
- `obshij-plan-zala.jpg`
- `maria-s-klientom.jpg`
- `detali-decora.jpg`
- `gosti-tancuyut.jpg`

Но если просто скопированы имена вида `IMG_2374.JPG` — тоже нормально, переименуем позже.

## Отзывы, логотипы, документы

- `logos/` — логотипы клиентов (если будут согласия на публикацию)
- `docs/` — сканы/PDF, если нужны (например, согласования)

Эти папки создадим по мере необходимости — пока не нужно.
